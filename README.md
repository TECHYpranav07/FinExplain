# 🏦 FinExplain — Evidence-First AI for Financial & Loan Decisions

**FinExplain** is an enterprise-grade, Agentic RAG (Retrieval-Augmented Generation) and proactive loan policy analysis platform. It bridges the gap between unstructured loan contracts and reliable financial decisions by enforcing **deterministic calculations**, **claim-level verbatim evidence citations**, **conflict detection**, and **multi-dimensional confidence scoring**.

---

## 🌟 Why FinExplain?

Standard LLM pipelines fail on financial agreements due to arithmetic hallucinations, missed conditional clauses (e.g., prepayments, fee waivers), and ungrounded assumptions. FinExplain solves this through:

- **Evidence-First Verification**: Every fact extracted is classified as `EXPLICIT`, `CONDITIONAL`, `INFERRED`, `NOT_SPECIFIED`, or `CONFLICTING` and mapped to verbatim document excerpts with exact page citations.
- **Deterministic Math Engine**: Financial math (EMIs, amortization schedules, prepayment penalties, processing fees, total scenario costs) is computed by dedicated Python financial calculators, never generated by LLM arithmetic.
- **Proactive Risk & Missing Information Audits**: Automatically analyzes documents to detect hidden cost drivers, missing rate disclosures, ambiguous clauses, and conflicting terms before you sign.
- **"Before You Confirm" Checklist**: Generates prioritized pre-commitment checklists and tailored questions to ask the lender.
- **Enterprise Dark-Mode Web Application**: Includes a comprehensive **Vite + React + TypeScript + Tailwind CSS** frontend with 14 modular pages, real-time citation inspector, and cloud video background.

## 🛠️ Technology Stack

| Layer | Technologies |
|---|---|
| **Frontend Application** | [React 18](https://react.dev/), [Vite](https://vitejs.dev/), [TypeScript](https://www.typescriptlang.org/), [Tailwind CSS](https://tailwindcss.com/), [TanStack Query](https://tanstack.com/query), [React Router](https://reactrouter.com/), [Lucide](https://lucide.dev/), Font Awesome 6.5.2 |
| **Typography & Design** | Google Fonts **Inter** (UI/body) + **BubbledotICG-FinePos** dot-matrix display font + deep dark enterprise palette (`#000000`, `#111111`, `#171717`) |
| **Backend & API** | Python 3.11+, [FastAPI](https://fastapi.tiangolo.com/), Pydantic v2, Uvicorn |
| **Embeddings** | SentenceTransformers (`all-MiniLM-L6-v2`, 384 dimensions), Hugging Face Inference API / PyTorch Fallback |
| **Hybrid Search** | [Pinecone](https://www.pinecone.io/) (Dense) + [Supabase PostgreSQL](https://supabase.com/) (`tsvector` BM25 Sparse) |
| **Reranking** | Cross-Encoder (`cross-encoder/ms-marco-MiniLM-L-6-v2`) |
| **LLM Engine** | [Groq API](https://groq.com/) (`llama3-70b-8192`, `llama-3.3-70b-versatile`) |
| **Document Processing** | PyMuPDF (`fitz`), Hierarchical Parent-Child Chunker |
| **Testing** | Pytest (22 deterministic scenario tests covering calculations, conflicts, and verification) |

## 💻 Quick Start & Running Locally

### 1. Backend Setup
```bash
# Clone the repository
git clone https://github.com/samadhanmane/FinExplain.git
cd fine-explain

# Create virtual environment
python -m venv .venv

# Activate virtual environment
# Windows:
.venv\Scripts\activate
# Linux / macOS:
source .venv/bin/activate

# Install backend dependencies
pip install -r requirements.txt

# Start FastAPI backend
cd backend
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

### 2. Frontend Setup (Development Server)
```bash
# In a new terminal:
cd fine-explain/frontend

# Install frontend dependencies
npm install

# Start Vite hot-reloading development server
npm run dev
```

- 🌐 **Vite Dev Server**: [http://localhost:5173](http://localhost:5173) (or `http://localhost:5174`)
- 🖥️ **FastAPI Integrated App**: [http://localhost:8000/app](http://localhost:8000/app)
- 📖 **Interactive Swagger API Docs**: [http://localhost:8000/docs](http://localhost:8000/docs)
- 📚 **ReDoc API Documentation**: [http://localhost:8000/redoc](http://localhost:8000/redoc)

## 🧪 Automated Testing Suite

FinExplain includes a comprehensive **22-scenario deterministic test suite** verifying calculation correctness, edge cases, citation auditing, and risk scoring without requiring external API credits:

```bash
# Run test suite
python -m pytest backend/tests/test_evidence_pipeline.py -v
```

### Test Coverage Highlights:
1. **Explicit Fee Extraction** — Accurately extracts stated percentage and fixed fees.
2. **Conditional Fees** — Detects fees triggered only under specific circumstances.
3. **Missing Disclosure Detection** — Identifies absent mandatory fee or APR terms.
4. **Conflicting Fee Clauses** — Detects contradictions across document sections.
5. **Early Repayment Penalty** — Analyzes lockout periods, formulas, and percentages.
6. **Fee Waiver Timing** — Correlates waivers against borrower tenure scenarios.
7. **Late Payment Penalties** — Evaluates penalty interest and grace period terms.
8. **Missing Late Payment Amount** — Flags missing penalty caps.
9. **Variable Interest Rate Rules** — Identifies benchmark spread mechanisms.
10. **Conflicting APR Terms** — Identifies APR discrepancies across agreements.
11. **Currency Conflict** — Identifies conflicting currencies across clauses.
12. **Prepayment Risk vs Scenario** — Flags early repayment penalties when scenario tenure is less than lockout period.
13. **Missing Calculation Input** — Prevents calculation with unverified parameters.
14. **Unsupported LLM Claim Penalty** — Penalizes confidence scores when LLM output lacks citation.
15. **Invalid Citation Page Verification** — Validates source page references against actual chunk pages.
16. **Deterministic Financial Math** — Verifies mathematical precision for EMI, interest, and total costs.
17. **Multi-Dimensional Confidence Scoring** — Evaluates evidence status weighting and penalization.
18. **Risk Severity Engine** — Validates composite risk scoring (0-100) and severity classifications.
