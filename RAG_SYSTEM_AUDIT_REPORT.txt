3. REMEDIATED FLAWS & APPLIED ENHANCEMENTS SUMMARY
--------------------------------------------------------------------------------

1. PII GUARD ACTIVATION:
   - File: `backend/app/rag/orchestrator.py`
   - Fix: Integrated `pii_guard.redact_pii(clean_question)` immediately after injection checks, preventing PAN, Aadhaar, and financial IDs from flowing to external LLM APIs.

2. RISK & CONFIDENCE PROMPT PAYLOAD INTEGRATION (Q4 RESOLVED):
   - Files: `backend/app/rag/generation/generator.py`, `prompt_templates.py`, `orchestrator.py`
   - Fix: Passed `risk_factors` and `risk_score_result` to `generate_answer()` and added dedicated placeholders in `QA_USER_PROMPT_TEMPLATE`. Enabled `is_meta_query` support in `evidence_scorer.py`.

3. FAST HEURISTIC QUERY REWRITING:
   - File: `backend/app/rag/enhancement/query_rewriter.py`
   - Fix: Added deterministic regex keyword mapping for standard entities (interest rate, processing fee, prepayment, late fee, tenure, EMI), eliminating 1 full LLM roundtrip on common queries.

4. MULTI-TENANT CACHE SCOPING & IN-MEMORY FALLBACK:
   - File: `backend/app/cache/query_cache.py`
   - Fix: Scoped cache key with `user_id` (`v2:{user_id}:{provider}:{model}:{query}:{product_ids}`) and added a 500-item in-memory LRU cache fallback.

5. CURRENCY OCR GLYPH NORMALIZATION:
   - File: `backend/app/ingestion/parser.py`
   - Fix: Added `_clean_extracted_text` to replace font-glitched `I` characters before numbers with proper `₹` / `INR` symbols.

6. ROBUST JSON ARRAY EXTRACTION:
   - File: `backend/app/rag/extraction/fact_extractor.py`
   - Fix: Added regex-based JSON array boundary extraction (`re.search(r'\[\s*\{.*\}\s*\]')`) to recover cleanly when LLM outputs conversational wrappers.
